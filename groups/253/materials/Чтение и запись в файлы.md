# Работа с файлами в C++


Для работы с файлами в C++ используется библиотека:

``` cpp
#include <fstream>
```

Она содержит классы для чтения и записи файлов.


# Основные классы для работы с файлами

В библиотеке `<fstream>` есть три основных класса.

| Класс     | Назначение               |
|-----------|--------------------------|
| `ifstream` | чтение данных из файла   |
| `ofstream` | запись данных в файл     |
| `fstream`  | чтение и запись файла    |

## ifstream

`ifstream` означает **input file stream** --- поток ввода из файла.

Используется, когда программа **читает данные** из файла.

## ofstream

`ofstream` означает **output file stream** --- поток вывода в файл.

Используется, когда программа **записывает данные** в файл.

## fstream

`fstream` --- более универсальный класс.

Он позволяет:

-   читать из файла
-   записывать в файл

То есть `fstream` объединяет возможности `ifstream` и `ofstream`.

Обычно:

-   `ifstream` используют только для чтения
-   `ofstream` используют только для записи
-   `fstream` используют, когда нужно делать **и чтение, и запись**.


# Чтение из файла

Чтение --- это получение данных из файла.

Для чтения используется объект типа `std::ifstream`.

## Пример чтения чисел

Файл `data.txt`:

    10
    20
    30

Программа:

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ifstream file("data.txt");

    int x;

    while (file >> x)
    {
        std::cout << x << std::endl;
    }

    file.close();
}
```

Как работает программа:

1.  `std::ifstream file("data.txt");` --- открываем файл
2.  `file >> x` --- читаем число
3.  `while` --- продолжаем чтение, пока данные есть
4.  `file.close()` --- закрываем файл

Вывод программы:

    10
    20
    30


# Чтение строк

Иногда нужно читать **целые строки текста**, а не отдельные слова или
числа.

Для этого используется функция `std::getline()`.

Файл `text.txt`:

    Hello
    How are you?
    I am fine

Программа:

``` cpp
#include <iostream>
#include <fstream>
#include <string>

int main()
{
    std::ifstream file("text.txt");

    std::string line;

    while (std::getline(file, line))
    {
        std::cout << line << std::endl;
    }

    file.close();
}
```

Файл читается **строка за строкой**.


# Запись в файл

Запись --- это сохранение данных программы в файл.

Для этого используется объект типа `std::ofstream`.

## Пример записи

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ofstream file("output.txt");

    file << "Hello world!" << std::endl;
    file << 123 << std::endl;

    file.close();
}
```

После выполнения программы файл `output.txt` будет содержать:

    Hello world!
    123


# Запись нескольких значений

Пример программы:

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ofstream file("numbers.txt");

    for (int i = 1; i <= 5; i++)
    {
        file << i << " ";
    }

    file.close();
}
```

Файл `numbers.txt`:

    1 2 3 4 5


# Чтение и запись в одной программе

Иногда нужно прочитать данные из одного файла и записать их в другой.

Пример:

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ifstream in("input.txt");
    std::ofstream out("output.txt");

    int x;

    while (in >> x)
    {
        out << x * 2 << std::endl;
    }

    in.close();
    out.close();
}
```

Если `input.txt` содержит:

    5
    10
    20

Файл `output.txt` будет:

    10
    20
    40


# Проверка открытия файла

Файл может не открыться (например, если его нет).

Поэтому лучше проверять это:

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ifstream file("data.txt");

    if (!file)
    {
        std::cout << "Ошибка открытия файла" << std::endl;
        return 1;
    }

    int x;

    while (file >> x)
    {
        std::cout << x << std::endl;
    }

    file.close();
}
```


# Мини‑пример

Программа сначала записывает число в файл, а затем читает его.

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::ofstream out("number.txt");
    out << 42;
    out.close();

    std::ifstream in("number.txt");

    int x;

    in >> x;

    std::cout << x << std::endl;

    in.close();
}
```

Вывод программы:

    42

# Использование fstream

`std::fstream` можно использовать, когда нужно **читать и записывать
один и тот же файл**.

Пример:

``` cpp
#include <iostream>
#include <fstream>

int main()
{
    std::fstream file("data.txt", std::ios::in | std::ios::out); // но писать режимы открытия не обязательно, они по дефолту такие

    int x;

    while (file >> x)
    {
        std::cout << x << std::endl;
    }

    file.close();
}
```

Здесь файл открыт сразу для:

-   чтения (`std::ios::in`)
-   записи (`std::ios::out`)

# Режимы открытия файлов

Когда файл открывается, можно указать **режим работы с файлом**.

Режим задаётся с помощью флагов из пространства имён `std::ios`.

Самые часто используемые режимы:

| Режим           | Назначение                     |
|-----------------|---------------------------------|
| `std::ios::in`  | открыть файл для чтения        |
| `std::ios::out` | открыть файл для записи        |
| `std::ios::app` | записывать данные в конец файла |

Флаги можно **комбинировать** с помощью оператора `|`.

Например:

``` cpp
std::fstream file("data.txt", std::ios::in | std::ios::out);
```

Это означает:

-   файл открыт для чтения
-   файл открыт для записи

# Дозапись в файл (`std::ios::app`)

По умолчанию `std::ofstream` **перезаписывает файл**.

Если нужно **добавлять данные в конец файла**, используется режим
`std::ios::app`.

Пример:

``` cpp
#include <fstream>

int main()
{
    std::ofstream file("log.txt", std::ios::app);

    file << "New record" << std::endl;

    file.close();
}
```

Если файл `log.txt` содержит:

    first
    second

После работы программы он станет:

    first
    second
    New record
